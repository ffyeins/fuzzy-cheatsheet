# Git Basics

Version control essentials.

## Staging Changes

Use `git add` to stage files:

```bash
git add file.txt
git add -A
```

## Committing

```bash
git commit -m "your message"
```

### Amending a Commit

```bash
git commit --amend
```

## Branching

Create and switch to a new branch:

```bash
git checkout -b feature-branch
```

### Deleting a Branch

```bash
git branch -d old-branch
```
